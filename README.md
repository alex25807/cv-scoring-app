# CV Scoring App (HH + LLM)

Учебный проект: Streamlit-приложение, которое парсит вакансию и резюме с HH.ru и оценивает соответствие кандидата вакансии с помощью LLM (OpenAI).

> Дисклеймер: проект учебный. Используется HTML-парсинг страниц. В реальности сайт может менять верстку, отдавать капчу/403/429 и т.п.

---

## Возможности

- Ввод ссылок на вакансию и резюме (HH.ru)
- Парсинг ключевых блоков (описание, опыт, навыки)
- LLM-анализ и скоринг в структурированном виде:
  - Fit score (1–10)
  - Skills match (1–10)
  - Experience relevance (1–10)
  - Resume quality (1–10)
- Сводка, плюсы/минусы, чего не хватает, рекомендации
